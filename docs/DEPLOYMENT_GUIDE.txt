Deployment Guide

Local deployment with Docker:
1. Copy .env.example to .env.
2. Run: docker compose up --build
3. Open frontend at http://localhost:5173
4. Open backend health check at http://localhost:5001/api/health

Local deployment without Docker:
1. Start backend using Python virtual environment.
2. Use SQLite by setting DATABASE_URL=sqlite:///local.db
3. Start frontend with npm run dev.

Cloud deployment with EC2 idea:
1. Use Terraform files under infra/terraform.
2. Fill terraform variables: ami_id, key_name and allowed_ip_cidr.
3. Run terraform init, terraform plan and terraform apply.
4. SSH to the server.
5. Install or clone the GitHub repository.
6. Run docker compose up -d --build.

Important:
Do not write real passwords, tokens or API keys inside the repository.
Use GitHub Secrets or server environment variables for production values.
